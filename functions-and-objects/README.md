# Функции и обекти – упражнение

Практически задачи по JavaScript (Node.js), без външни библиотеки.

## Какво ще упражним

1. **Функции:** параметри, извикване и върнати стойности (`return`)
2. **Функции като параметри:** функции от по-висок ред и функции, които връщат функции
3. **Анонимни функции и callback функции:** function expression, arrow функции, `setTimeout`, `map` / `filter` / `reduce` / `forEach`

Обектите присъстват във всяка тема: създаваме ги, четем и променяме свойствата им и пишем методи с `this`.

## Как се стартира

Трябва ви инсталиран [Node.js](https://nodejs.org) (версия 18 или по-нова).

```bash
cd functions-and-objects
node 01-functions-basics/01-sum-numbers.js
```

Всеки файл отпечатва резултата от тестовете си:

```
✅ sumNumbers(2, 3)
   Очаквано: 5 | Получено: 5
```

`✅` означава, че резултатът съвпада с очаквания, а `❌` – че не съвпада.

Как да стартирате всички файлове наведнъж:

```bash
# Git Bash / macOS / Linux
for f in */*.js; do echo "== $f"; node "$f"; done
```

```powershell
# PowerShell
Get-ChildItem -Recurse -Filter *.js | ForEach-Object { "== $($_.Name)"; node $_.FullName }
```

## Задачите накратко

### Тема 1: Функции – основи

| # | Задача | Какво упражнява |
|---|--------|-----------------|
| 1 | Сбор на числа | параметри по подразбиране, `return` срещу `console.log`, функция без `return` връща `undefined` |
| 2 | Минимум, максимум, средно | няколко върнати стойности чрез **масив** `[min, max]` и **обект** `{ min, max, average }`, деструктуриране |
| 3 | Ученическа карта | функция, която **връща обект** с методи, `this`, достъп с `.` и `[]` |

### Тема 2: Функции като параметри

| # | Задача | Какво упражнява |
|---|--------|-----------------|
| 1 | Калкулатор | собствена функция от по-висок ред `calculate(a, b, operation)`, подаване на **именувана** функция |
| 2 | Собствени map и filter | `applyToEach` и `keepOnly`, комбиниране на функции, масив от обекти |
| 3 | Фабрика за валидатори | **функция, която връща функция** (closure), обект от правила с масиви от функции |

### Тема 3: Анонимни функции и callback функции

| # | Задача | Какво упражнява |
|---|--------|-----------------|
| 1 | Три начина да запишем функция | declaration, **function expression**, **arrow** функции, връщане на обект `({ ... })`, обект с анонимни методи |
| 2 | Callback-и със setTimeout | `setTimeout`, error-first callback `(error, data)`, ред на изпълнение на асинхронния код |
| 3 | Обработка на продукти | масив от обекти `{ name, price, category, quantity }`, обработен с `map`, `filter`, `reduce` и `forEach`, верига от методи |

## Как да работите със задачите

Задачите са дадени заедно с решенията. Ето как да ги използвате най-пълноценно:

1. **Прочетете условието** в коментара най-горе във файла.
2. **Решете задачата сами:** копирайте файла, изтрийте решението и напишете свое.
3. **Стартирайте** и проверете дали всички тестове показват `✅`.
4. **Сравнете** със зададеното решение. Какво направихте различно?
5. **Добавете поне един свой тест**, напр. за празен масив, отрицателно число или липсващ параметър.

### Как да използвате ИИ асистента

- Помолете го да **обясни** конкретен ред: *„Защо в `createPoint` обектът е в кръгли скоби?“*
- Помолете за **подсказка, а не за решение**: *„Дай ми насока как да намеря минимума без Math.min.“*
- Нека ви **изпита**: *„Задай ми 3 въпроса за разликата между map и forEach.“*
- Поискайте **преглед на кода**: поставете своето решение и попитайте какво може да се подобри.
- Винаги **стартирайте** кода, който ви предложи. Тестовете казват истината, а не асистентът.
